# 🇮🇪 Ireland Weather Hub

A real-time weather monitoring and analytics dashboard for 10 Irish cities, built with Python and Streamlit. Pulls live 24-hour forecasts from the Open-Meteo API, stores them in PostgreSQL (with a CSV fallback), and visualises rainfall, temperature, wind, and pressure on an interactive map and chart suite.

## Features

### Dashboard

| Section | What it shows |
|---|---|
| **Hero Banner** | Date/time, active city count, data source, last sync time |
| **KPI Cards** | Peak rain probability · Wettest location · Average temperature · Active rain zones (≥ 70 % chance) |
| **City Snapshots** | Per-city cards with weather icon, temperature, precipitation, wind label, and rain intensity badge |
| **Live Rainfall Map** | Mapbox scatter map colour-coded by rain probability; click any dot to zoom in, click again to reset |
| **24-Hour Analytics** | Four tabs — Rainfall, Temperature & Humidity, Wind & Pressure, Hour Snapshot radar |
| **Raw Data** | Expandable table for the selected forecast hour with progress-bar columns |

### Sidebar Controls

- **Refresh** — re-fetches data on demand (PostgreSQL first, CSV fallback)
- **City filter** — multiselect (default: all 10 cities; "All Cities" chip selects everything)
- **Forecast hour** — slider across the 24-hour window
- **Rain threshold** — show only cities above a minimum probability %
- **Data source badge** — green = PostgreSQL live, yellow = CSV cache

## Data Pipeline

```
Open-Meteo Forecast API
        │
        ├─── fetch_weather.py ──────────────► data/live_weather.csv
        │                                           │
        └─── fetch_weather_to_postgres.py ─► PostgreSQL: live_weather
                                                    │
                                                    ▼
                                              app.py (reads both,
                                              PostgreSQL preferred)

Open-Meteo Archive API
        │
        └─── fetch_historical_weather.py ──► PostgreSQL: weather_history
                                                    │
                                                    ▼
                                          prepare_ml_dataset.py
                                                    │
                                                    ▼
                                          data/ml_weather_dataset.csv
```

### Variables fetched per city per hour

| Column | Description |
|---|---|
| `temperature` | Temperature at 2 m (°C) |
| `humidity` | Relative humidity at 2 m (%) |
| `precipitation` | Precipitation amount (mm) |
| `precipitation_probability` | Chance of rain (%) |
| `pressure` | Mean sea-level pressure (hPa) |
| `cloud_cover` | Total cloud cover (%) |
| `wind_speed` | Wind speed at 10 m (km/h) |

## PostgreSQL Schema

Two tables are used:

**`live_weather`** — today's hourly forecast (appended each refresh)

```sql
city                    TEXT
latitude                FLOAT
longitude               FLOAT
forecast_time           TIMESTAMP
temperature             FLOAT
humidity                FLOAT
precipitation           FLOAT
precipitation_probability FLOAT
pressure                FLOAT
cloud_cover             FLOAT
wind_speed              FLOAT
loaded_at               TIMESTAMP
```

**`weather_history`** — historical archive 2024–2025, unique on `(city, weather_time)`

```sql
city          TEXT
latitude      FLOAT
longitude     FLOAT
weather_time  TIMESTAMP  -- PRIMARY KEY component
temperature   FLOAT
humidity      FLOAT
precipitation FLOAT
rain          FLOAT
pressure      FLOAT
cloud_cover   FLOAT
wind_speed    FLOAT
loaded_at     TIMESTAMP
UNIQUE (city, weather_time)
```

## ML Dataset

`prepare_ml_dataset.py` reads `weather_history` and engineers features for rainfall prediction:

| Feature | Description |
|---|---|
| `hour`, `day`, `month`, `day_of_week` | Time-based features |
| `precipitation_lag_1` | Precipitation from 1 hour ago (per city) |
| `humidity_lag_1` | Humidity from 1 hour ago (per city) |
| `cloud_cover_lag_1` | Cloud cover from 1 hour ago (per city) |
| `temp_rolling_3` | 3-hour rolling mean temperature (per city) |
| `humidity_rolling_3` | 3-hour rolling mean humidity (per city) |
| **`rain_next_hour`** | **Target — binary: will it rain in the next hour?** |

Output saved to `data/ml_weather_dataset.csv`.

## Quick Start

### 1. Clone and set up environment

```bash
git clone https://github.com/varadkamtikar/Ireland-Weather-Hub.git
cd Ireland-Weather-Hub
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Configure environment variables

Create a `.env` file in the project root:

```env
DB_USER=your_postgres_user
DB_PASSWORD=your_postgres_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=your_database_name
```

> **No PostgreSQL?** Skip this step — the dashboard automatically falls back to the CSV file.

### 3. Fetch live weather data

**CSV mode (no database needed):**
```bash
python src/fetch_weather.py
```

**PostgreSQL mode:**
```bash
python src/fetch_weather_to_postgres.py
```

### 4. Run the dashboard

```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

## Optional: Historical Backfill & ML Dataset

```bash
# Pull 2 years of hourly data for all 10 cities into PostgreSQL
python src/fetch_historical_weather.py

# Build ML-ready feature dataset
python src/prepare_ml_dataset.py
```

The historical pull covers **2024-01-01 to 2025-12-31** and uses the Open-Meteo Archive API. Duplicate records are handled with `ON CONFLICT DO UPDATE`, so re-runs are safe.

## Data Refresh Logic

The dashboard caches data for **5 minutes** (`@st.cache_data(ttl=300)`). On refresh:

1. Tries `fetch_weather_to_postgres.py` — if it succeeds, clears cache and rerenders.
2. Falls back to `fetch_weather.py` (CSV) if PostgreSQL is unavailable.
3. Shows an error if both fail.

The active data source is always visible in the sidebar badge (green = PostgreSQL, yellow = CSV).

---

## Data Source

Weather data is provided by **[Open-Meteo](https://open-meteo.com)** — a free, open-source weather API that requires no API key. Forecast data uses the `/v1/forecast` endpoint; historical data uses the `/v1/archive` endpoint.
